Leonida Trophy Guide: an offline guide and tracker for all 55 Grand Theft Auto VI trophies on PlayStation 5. Every trophy carries its official name, description and grade plus a guide in our own words with steps, a tip and cited sources. A 3-stage roadmap to the platinum (~200 hours, 4/10), a missables view built around the game's one missable trophy, and a checklist that saves in the browser with filters (story, missable, collectibles, activities, side quests, robberies, online), a spoiler-free mode, search, sorting, and export/import of progress. Static files under app/, no build step, no network at run time.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. To build the submission output:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
